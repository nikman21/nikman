# Mobile text and spacing review

Reviewed the live site in the Codex in-app browser on November 4, 2026. The baseline covers all 36 HTML pages at 390 and 320 pixels wide: the homepage, About, project and writing indexes, Now and its archive, Index, Principles, Commonplace, Garden, seven project pages, five essays, seven garden articles, five older note URLs, and the 404 page.

This is a browser viewport review. It does not establish physical iPhone or Safari behavior. RSS and JSON endpoints are not visual pages.

## Changes

- Removed the fixed 320-pixel body minimum. With a classic vertical scrollbar, the 320-pixel viewport had only 305 pixels available and scrolled horizontally. The local retest now fits that available width.
- Gave mobile page titles and archive headings more line spacing. Reduced the mobile title size slightly and let principle headings use the available width.
- Reduced excessive gaps between article metadata and removed the extra margin above a first body heading. Later body headings keep a clear section gap.
- Moved each garden card’s update date alongside its status, instead of leaving it in a separate row below the summary.
- Put connected-note maturity labels below the title and increased them from 10.4 to 12 pixels. Titles have more horizontal room at narrow widths.
- Put Commonplace source and reflection links on separate rows, keeping their 44-pixel minimum height.
- Kept related-reading arrows attached to the preceding title word so an arrow cannot sit on a line by itself.
- Matched older note-page mobile sizing and spacing to the current writing section. Removed the outdated publishing explanation from the older index; its canonical URL and noindex metadata remain.
- Renamed the visible Hatch references to Mavo. `/about/#mavo` is the new section anchor; the former `#hatch` anchor still reaches its heading.

The article bodies, quotations, project claims, photos, and video files were not rewritten in this pass.
